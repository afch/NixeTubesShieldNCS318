Format: hh:mm:ss
Mode – long press: enter setup mode; short press: move to the next digit; after the last digit – exit.
Mode – short press: start/stop.
UP/DOWN – in setup mode increases or decreases each digit individually.
UP - reset (and stop)
Down - set 0

IR Remote Keys:
MENU/MODE - enter and exit setup mode
LEFT/RIGHT - move edit position
UP/DOWN – in setup mode increases or decreases each digit individually.
Enter - Start/Stop timer
OFF - On/Off the device
